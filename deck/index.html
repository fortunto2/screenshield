ScreenShield

Video is an untrusted channel. Secrets leak out, attacks come in.
Live in seconds, across the archive in minutes.

One Rust binary · fast loop on the device · agent over the archive

Every classroom and boardroom records a screen

Leaks out

  • .env, API keys, DB URLs during dev workshops and town halls
  • Grades, e-mails, LMS tabs in lectures (a listed FERPA violation)
  • A recording in which a student is identifiable is part of their education record

Attacks in

  • Quishing: one QR on a slide, 300 phones scan it; 67% sign in through a malicious QR (field study)
  • Visual prompt injection: agents now watch camera feeds through MCP; text in the frame steers them
  • VPI-Bench (ICLR 2026): up to 100% success against computer-use agents

Nobody owns this: the leak is the presenter's mistake, so nobody asks the vendor and nobody sells a fix.

Two loops, two speeds

FAST LOOP · online · on the device

Protection module. No LLM. Works offline.

  • keyframes → OCR + QR → detectors → gates → blur → events
  • 0.3–0.8 s per keyframe on a MacBook, Apple Vision on-device
  • Runs where the stream is: Pearl-class encoder, Mac, SRT/RTMP ingest

SLOW LOOP · offline · the agent

Autonomous audit of the archive. Batch, nightly.

  • Vision model only where regexes are blind (grades, mail, payments)
  • Decides per policy; redacts, revokes, applies retention, writes the evidence log
  • Produces the dataset the fast loop learns from

The agent is too slow for the stream, so it never sits in it. The fast loop is too dumb for context, so it never decides alone.

Fast loop: what happens to a frame

screen · camera · SRT/RTMP→ keyframes (dHash, va-scene next)→ OCR + QR (Apple Vision)→ detectors: leak · quishing · injection→ gates→ blur in recording→ ClickHouse events

leak

AWS, GitHub, Stripe, OpenAI, Slack keys; private-key blocks; JWT; password=; DB URLs; env secrets; e-mail, SSN, Luhn-checked cards

quishing

QR → URL: shortener, raw IP, suspicious TLD, brand lookalike, plain http; action QRs (wifi, otpauth)

injection

override instructions, agent address, system-prompt markers, tool-call requests, device-control verbs, exfil verbs. Lines joined: instructions span OCR rows.

14 frames at 2 fps → 2 keyframes → 7 findings in 0.8 s. Redaction verified: after the blur, OCR no longer reads the key and the QR no longer decodes.

Gates for any agent that watches the feed (DRIFT, Li & Xiao, NeurIPS 2025)

Control constraints

Read tools pass. Write tools are an allowlist. factory_reset, set_admin_password always need a human.

Data provenance (taint)

Every token seen in a frame is remembered for 120 s. A tool argument containing one is blocked: the value came from external content.

Approved destinations

set_stream_destination only to hosts in policy. The frame can never extend the allowlist.

Injection isolator

Frame text handed to an agent has instruction-like lines replaced by [external content removed]. It learns that there was text, never what it ordered.

Deterministic, outside the model. VLMs score 100% unsafe on "move the knife" frames (Xiao); the gate cannot rely on the model refusing.

The responder agent

Input

  • one finding (kind, rule, severity, box, time)
  • policy from Senso: approved destinations, allowed QR domains, sensitive classes
  • fleet facts from ClickHouse: "this QR is already in 31 rooms"

Tools

redact_segment revoke_credential block_destination notify_human apply_retention write_incident

Runtime

  • sgr-agent (Rust) tool calling on an open model via AkashML (gpt-oss-120b)
  • Rule-based planner when offline: same tools, same log
  • Every call passes the same gates; dry-run by default
  • Human before anything that drops a live stream
  • Always ends with write_incident: the evidence log is the product

ClickHouse: the fleet, not the frame

No embeddings of ordinary screens. Vectors only for flagged frames and per-room baselines: unknown attacks show up as anomaly against the room's own normal, not as kNN to examples we do not have.

Why this, why now

Context

Pearl-class lecture-capture encoders push SRT/RTMP from thousands of rooms. The moment such devices open to AI agents, the video itself becomes an attack surface (Mike Sandler, Epiphan). Chaowei Xiao (JHU / NVIDIA) said the same at Stanford this week.

What customers actually ask for

Not "blur". SOC 2, HIPAA, VPAT, DPA, retention policy. ScreenShield answers the questionnaire with an artifact: the recording leaves with secrets removed, and every case has a log.
